# Передбачення: правила Markdown

## Передбачення 1. Два рядки без порожнього рядка між ними

```
Перший рядок
Другий рядок
```

Передбачення: перегляд покаже **один рядок**. Markdown склеює сусідні рядки в один абзац, а новий абзац починається лише після порожнього рядка.

Показав: `<p>Перший рядок Другий рядок</p>` — обидва рядки в одному абзаці, тобто на екрані один рядок. Я вгадала, бо одинарний перенос рядка Markdown вважає просто пробілом. (Цікаво: у коментарях GitHub, режим `gfm`, той самий текст показався двома рядками через `<br>` — там правила інші.)

## Передбачення 2. Нумерація списку

```
1. один
1. два
1. три
```

Передбачення: побачу **1, 2, 3**. Markdown нумерує список сам, цифра в тексті важлива лише для першого пункту.

Показав: нумерований список `<ol>` з номерами 1, 2, 3. Я вгадала, бо номери в списку рахує Markdown, а не я.

## Передбачення 3. Чи буде слово жирним?

```
Це **жирний ** текст
```

Передбачення: **не буде жирним**, зірочки лишаться видно. Через пробіл перед закривними `**` Markdown не вважає їх кінцем виділення.

Показав: `Це **жирний ** текст` — звичайний текст разом із зірочками. Я вгадала, бо закривні `**` не можуть стояти після пробілу.

## Передбачення 4. Чи буде це таблицею?

```
| А | Б |
| 1 | 2 |
```

Передбачення: **не буде таблицею**, а звичайним текстом в один рядок. Без рядка з дефісами Markdown не розуміє, що це таблиця.

Показав: звичайний абзац `| А | Б | | 1 | 2 |` — рядки склеїлись, таблиці немає. Я вгадала, бо таблиця в Markdown обовʼязково потребує рядка `|---|---|` під заголовком.
