# Передбачення: що Python прочитає з pastky.yaml

| Ключ | Моє передбачення: значення і тип | Показав perevir.py |
|---|---|---|
| svitlo | `False`, логічне — YAML читає `off` як «ні» | `False`, логічне — вгадала |
| pochatok | `2026-09-28`, дата, а не рядок | `datetime.date(2026, 9, 28)`, дата — вгадала |
| kod_dostupu | `8`, ціле — нуль на початку означає вісімкове число | `8`, ціле число — вгадала |
| limit | `'1e3'`, рядок — PyYAML не вважає запис без крапки дробовим числом | `'1e3'`, рядок — вгадала |
| port | `8080`, ціле — `0x` означає шістнадцяткове число | `8080`, ціле число — вгадала |
| komentar | `None`, порожнє — `~` у YAML означає «нічого» | `None`, порожнє — вгадала |

Найбільше здивувала пастка `limit`: `1e3` виглядає як число, а Python отримує рядок `'1e3'`, і програма впаде лише тоді, коли спробує з ним рахувати. Неприємна й `kod_dostupu`: код `010` тихо перетворився на `8`, і помилки ніхто не побачить. Обійти всі ці пастки можна, якщо брати такі значення в лапки, — тоді YAML нічого не «вгадує» і залишає рядок рядком.
