# Межа регулярних виразів

Регулярними виразами не варто розбирати вкладені структури — наприклад, JSON-конфіг бота з роботи 4. У ньому блок `discord` лежить усередині іншого блоку, а регулярка не вміє рахувати, яка дужка до якої належить, тому на першому ж вкладеному блоці вона почне помилятися. Для таких файлів є готовий парсер (`json.load`), який точно знає правила формату, а регулярки краще лишити для простих шаблонів у рядку — час, дата, IP.
